# Guia de estudo DP-300 — Administering Microsoft Azure SQL Solutions

Notas de estudo para o exame **Microsoft Certified: Azure Database Administrator Associate**.
Leia o guia em **2 dias (~8 horas)** e depois pratique com questões de múltipla escolha (MCQs).

## Informações sobre a prova (verificadas em 29 de outubro de 2026)

| Item | Detalhe |
|------|--------|
| Exame | DP-300: Administering Microsoft Azure SQL Solutions |
| Nível | Intermediário (Associate) |
| Duração | 100 minutos, com supervisão. Algumas questões podem ser interativas, com labs ou drag-and-drop |
| Nota de corte | 700 de 1000 |
| Nova tentativa | Após 24 horas na primeira reprovação. O intervalo é maior nas tentativas seguintes |
| Renovação | A cada 12 meses, com uma avaliação online **gratuita** no Microsoft Learn |
| Idiomas | Inglês, chinês (simplificado e tradicional), japonês, coreano, francês, alemão, português (Brasil), italiano e espanhol |
| Recursos em preview | A maioria das questões aborda recursos em General Availability (GA). Recursos populares em preview também podem aparecer |

## Atualizações recentes

- **27 de outubro de 2026: nova versão do exame em inglês.** Houve uma alteração pontual. O objetivo “Implement Always Encrypted with **VBS** enclaves” passou a ser “Implement Always Encrypted with **secure** enclaves”. Estude os dois tipos (VBS e Intel SGX) no [Módulo 2 › Criptografia](<Module 2 - Implement a Secure Environment>).
- As versões traduzidas do exame são atualizadas cerca de 8 semanas após a versão em inglês.
- **A avaliação prática passou para o AI Skills Navigator.** Faça login na plataforma para iniciá-la.
- **A DP-300 continua ativa.** O exame DP-100 foi descontinuado em 2026.
- Ferramentas descontinuadas ainda podem aparecer nas questões, como Data Migration Assistant (DMA), Azure Data Studio e sua extensão de migração, e o DMS clássico para SQL. As lições indicam o substituto de cada uma.
